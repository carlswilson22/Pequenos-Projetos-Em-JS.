# 🚀 Projetos Front-End com HTML5, CSS3 e JavaScript

Este repositório foi criado para centralizar pequenos projetos e laboratórios práticos de Front-End, com foco na aplicação de conceitos sólidos de lógica, padrões de projeto e arquitetura de software utilizando **JavaScript Vanilla**.

---

## 💡 Conceitos e Pilares Abordados

Abaixo estão listados os pilares técnicos fundamentais implementados e exercitados no desenvolvimento destes projetos com foco em JavaScript:

*   **Injeção de Dependência:** Desacoplamento de componentes, garantindo que o código seja altamente testável, flexível e modular.
*   **Programação Defensiva:** Implementação de verificações rigorosas e validações de dados nas entradas para antecipar falhas e garantir a resiliência do sistema.
*   **Estruturas de Decisão:** Fluxos condicionais limpos, inteligentes e legíveis, evitando códigos aninhados complexos (*Arrow Anti-Pattern*).

---

## 📁 Projetos JavaScript

Aqui está a relação dos módulos desenvolvidos e o foco prático de cada um deles:

### 💵 Projeto 1: Sistema de Cobrança de Mensalidade
*   **Descrição:** Código estruturado para gerenciar e automatizar fluxos de cobrança recorrente.
*   **Conceito Focado:** *Programação Defensiva e Estruturas de Decisão* (validação de estados e ciclos de pagamento).

### 🏷️ Projeto 2: Aplicação de Desconto em Itens
*   **Descrição:** Algoritmo para cálculo dinâmico e aplicação de regras de descontos em itens/carrinho de compras.
*   **Conceito Focado:** *Estruturas de Decisão* (tratamento de diferentes regras e cupons de benefícios).

### ⚖️ Projeto 3: Compra com Cálculo de Imposto
*   **Descrição:** Módulo financeiro desenhado para calcular impostos de forma flexível a partir de diferentes origens ou tipos de produtos.
*   **Conceito Focado:** *Injeção de Dependência* (passagem dinâmica de motores de cálculo de impostos).

### 📊 Projeto 4: Padronização de Relatórios (Generics)
*   **Descrição:** Arquitetura para padronizar a geração e estruturação de relatórios para diferentes tipos de entidades e setores do sistema.
*   **Conceito Focado:** *Injeção de Dependência e Polimorfismo* (criação de uma interface comum de abstração para múltiplos formatos).

### ⚙️ Projeto 5: Processamento em Lote (Batch) com Auditoria
*   **Descrição:** Sistema avançado voltado ao processamento de dados massivos, focado na segurança, integridade dos dados e geração de logs estruturados.
*   **Conceito Focado:** *Programação Defensiva e Auditoria* (garantia de rastreabilidade de dados e prevenção a falhas em lotes).

## 🛠️ Tecnologias Utilizadas

*   **HTML5** — Estruturação semântica
*   **CSS3** — Estilização moderna e responsiva
*   **JavaScript (ES6+)** — Lógica orientada a objetos, boas práticas e manipulação do DOM
